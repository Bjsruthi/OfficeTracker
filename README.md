# 🏢 Office Calendar App

A simple personal calendar app to track office days.

## ✨ Features

* 📅 Monthly calendar view
* 🏢 Double-click/tap a day to mark it as an office day
* 💾 Automatically saves office days using browser local storage
* 📊 Displays the number of office days
* 🌙 Dark-themed UI
* 📱 Responsive design
* ⚡ Works offline
* 📲 Installable as a PWA

## 🛠️ Built With

* HTML
* CSS
* JavaScript
* Progressive Web App (PWA)
* Local Storage

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/Bjsruthi/OfficeTracker.git
cd OfficeTracker
```

Start a local server:

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## 📱 How to Use

1. Open the calendar.
2. Double-click or double-tap any date.
3. The date will be marked with 🏢.
4. Your office days are saved automatically.
