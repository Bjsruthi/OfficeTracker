### Path 1: Test Locally (10 minutes)
```

   ↓
2. Start local server (python -m http.server 8000)
   ↓
3. Open http://localhost:8000
   ↓
4. Test features
```

### Path 2: Deploy to GitHub (30 minutes)
```
1. SETUP.md (follow all phases)
   ↓
2. Create GitHub account
   ↓
3. Create repository
   ↓
4. Upload files via git
   ↓
5. Enable GitHub Pages
   ↓
6. Get live URL at https://USERNAME.github.io/office-calendar
```

### Path 3: Deploy to Netlify (5 minutes)
```
1. DEPLOYMENT.md → Netlify section
   ↓
2. Sign up with GitHub
   ↓
3. Import your repository
   ↓
4. Done! Live at https://[name].netlify.app
```

### Path 4: Install on Phone (10 minutes)
```
1. Open app in phone browser
   ↓
2. QUICKSTART.md → Mobile section
   ↓
3. Follow install instructions for iOS/Android
   ↓
4. App on home screen
```

6. **Update via Git** - Makes maintenance easy
